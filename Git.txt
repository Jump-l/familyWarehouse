### Git 操作提示手册

**一、 初始设置（首次使用Git时配置）**

1.  **设置用户名和邮箱（全局配置，提交时会记录此信息）**
    ```bash
    git config --global user.name "你的用户名"
    git config --global user.email "你的邮箱"
    ```

2.  **检查当前配置**
    ```bash
    git config --list
    ```

**二、 创建仓库与克隆**

1.  **在当前目录初始化一个新的Git仓库**
    ```bash
    git init
    ```

2.  **克隆一个现有的远程仓库到本地**
    ```bash
    git clone <远程仓库URL>
    # 例如： git clone https://github.com/用户名/仓库名.git
    ```

**三、 日常基本工作流程（最常用）**

1.  **检查仓库状态**（查看哪些文件被修改、暂存等）
    ```bash
    git status
    ```

2.  **将文件添加到暂存区**（准备提交）
    ```bash
    git add <文件名>        # 添加特定文件
    git add .              # 添加所有当前目录下的新文件和修改过的文件
    git add -A             # 添加所有变化（包括新建、修改、删除）
    ```

3.  **提交更改到本地仓库**（为本次更改创建一个版本记录）
    ```bash
    git commit -m "提交说明信息"
    # 提交说明应简洁明了，例如：git commit -m "修复用户登录bug"
    ```

4.  **将本地提交推送到远程仓库**
    ```bash
	# 已经有仓库，先添加远程仓库
	git remote add origin https://github.com/Mark-SmallCharlie/C-sharp-WPF.git（例）
	
    git push origin <分支名>
    # 例如： git push origin main
    # 首次推送可使用 -u 选项设置上游分支： git push -u origin main
    ```

5.  **从远程仓库拉取最新更改到本地**
    ```bash
    git pull origin <分支名>
    # 相当于 git fetch（获取） + git merge（合并）

   # 查看当前远程仓库配置 
  	git remote -v
  # 如果URL有误，可以重新设置
	git remote set-url origin https://github.com/Mark-SmallCharlie/C-sharp-WPF.git

    ```

**四、 分支管理**

1.  **查看所有分支**
    ```bash
    git branch              # 查看本地分支（当前分支前有 * 号）
    git branch -a           # 查看所有分支（包括远程分支）
    ```

2.  **创建新分支**
    ```bash
    git branch <新分支名>
    ```

3.  **切换到指定分支**
    ```bash
    git checkout <分支名>
    ```

4.  **创建新分支并立即切换到该分支**（常用）
    ```bash
    git checkout -b <新分支名>
    ```

5.  **将指定分支合并到当前分支**
    ```bash
    git merge <要合并过来的分支名>
    ```

6.  **删除分支**
    ```bash
    git branch -d <分支名>          # 删除已合并的分支
    git branch -D <分支名>          # 强制删除分支（即使未合并）
    ```

**五、 查看信息与撤销**

1.  **查看提交历史**
    ```bash
    git log                 # 查看详细历史
    git log --oneline       # 查看简洁版历史
    ```

2.  **查看文件更改的具体内容**
    ```bash
    git diff                # 查看工作区与暂存区的差异
    git diff --staged       # 查看暂存区与最后一次提交的差异
    ```

3.  **撤销操作**
    ```bash
    # 从暂存区撤销某个文件的添加（文件修改内容仍保留在工作区）
    git restore --staged <文件名>

    # 丢弃工作区中某个文件的修改（危险操作，不可恢复！）
    git restore <文件名>

    # 撤销上一次提交，并保留更改到工作区，允许你重新提交
    git reset --soft HEAD~1

    # 撤销上一次提交，并丢弃所有更改（危险操作！）
    git reset --hard HEAD~1
    ```

**六、 远程仓库操作**

1.  **查看远程仓库信息**
    ```bash
    git remote -v
    ```

2.  **添加远程仓库地址**
    ```bash
    git remote add origin <远程仓库URL>
    ```

3.  **修改远程仓库地址**
    ```bash
    git remote set-url origin <新的远程仓库URL>
    ```

4.  **从远程获取分支信息但不自动合并**
    ```bash
    git fetch
    ```

**七、 解决推送冲突的典型流程**

当 `git push` 失败，提示需要先 `git pull`，而 `git pull` 又产生合并冲突时：

1.  **拉取远程代码**
    ```bash
    git pull origin main
    ```

2.  **手动解决冲突**
    *   编辑文件中标记有 `<<<<<<<`, `=======`, `>>>>>>>` 冲突的地方。
    *   保留想要的代码，删除冲突标记。

3.  **重新添加并提交**
    ```bash
    git add .
    git commit -m "解决合并冲突"
    ```

4.  **再次推送**
    ```bash
    git push origin main
    ```

***
**提示：**
*   操作前先使用 `git status` 查看状态是一个好习惯。
*   谨慎使用 `--hard` 和 `-D` 等强制选项，可能导致数据丢失。
*   不确定时，可以先在测试分支上尝试操作。
