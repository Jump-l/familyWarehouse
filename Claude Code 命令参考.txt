一、内置 CLI 命令（Built-in CLI Commands）
================================================================================

/help
  显示帮助信息，列出所有可用命令和使用说明。

/clear
  清除当前对话历史，开始一个新的对话上下文。
  注意：不会删除记忆（memory）中的内容。

/fast
  切换快速模式。开启后使用更快的模型进行回复，
  适合简单快速的问答；关闭则使用完整模型，适合复杂推理。

/compact
  手动压缩对话上下文。当对话过长时，将前面的内容压缩为摘要，
  释放上下文空间，让后续对话保持流畅。

/status
  显示当前会话状态，包括：模型版本、token 用量、连接状态、
  当前工作目录、Git 分支等信息。

/upgrade
  检查并升级 Claude Code 到最新版本。

/doctor
  运行诊断工具，检查环境配置是否正确（Node.js版本、网络连接、
  权限设置等），帮助排查问题。

/model
  切换 AI 模型。可以指定不同模型（如 Opus、Sonnet、Haiku 等），
  根据任务复杂度选择合适的模型。

/theme
  设置终端主题样式，包括颜色方案、字体等显示偏好。

/insights
生成使用报告网站

/cost
使用消费量

/context
使用情况状态

/compact

二、代码工作流命令（Code Workflow Commands）
================================================================================

/init
  初始化项目。分析当前项目结构，生成 CLAUDE.md 项目配置文件，
  帮助 Claude 更好地理解你的项目。

/code-review [--comment] [--fix]
  代码审查。检查当前 git diff 中的改动，查找 bug、代码重复、
  简化机会和效率问题。支持三个级别：
    · 默认：输出审查报告到终端
    · --comment：将审查结果作为 PR 行内评论发布
    · --fix：自动将审查建议应用到代码中

/review
  拉取请求（PR）审查。对当前 PR 进行全面审查，包括代码质量、
  安全性、性能和最佳实践。

/security-review
  安全审查。专门检查代码中的安全漏洞，包括注入攻击、敏感信息泄露、
  权限问题、依赖漏洞等。

/simplify
  代码简化。审查改动的代码，关注：复用性、简化逻辑、
  提升代码效率、减少冗余。仅关注质量问题，不查找 bug。
  查找 bug 请使用 /code-review。

/verify
  验证代码变更。运行应用并观察行为，确认修改是否达到预期效果。
  可用于验证 PR、确认 bug 修复、手动测试功能等。

/run
  启动并运行项目应用。自动检测项目类型（Web 应用、CLI 工具、
  移动端等），选择合适的启动方式，查看变更的实际运行效果。

/loop [间隔时间] [命令]
  循环执行某个命令。比如 "/loop 5m /verify" 每5分钟验证一次。
  不指定间隔则由 AI 自行判断执行节奏。

三、项目与配置命令（Project & Config Commands）
================================================================================

/config
  打开或修改 Claude Code 的配置文件（settings.json）。
  可以设置主题、模型、权限、环境变量等。

/update-config
  通过 AI 对话的方式配置 settings.json。用于设置：
    · 自动化行为（hooks）："每次保存后运行测试"
    · 权限："允许 npm 命令"、"添加某工具的权限"
    · 环境变量："设置 DEBUG=true"
    · 迁移权限设置到不同层级

/keybindings-help
  自定义键盘快捷键。用于修改按键绑定、添加组合快捷键、
  修改提交键等。配置文件在 ~/.claude/keybindings.json。

/fewer-permission-prompts
  减少权限弹窗。扫描你的对话记录，找出常见的只读 Bash 和
  MCP 工具调用，自动添加到项目的 allowlist 中，
  减少反复询问权限的烦恼。

/permissions
  管理工具的权限设置。可以查看、添加、移除各工具的权限规则，
  支持全局、项目、会话三个级别。

/add-dir [目录路径]
  添加工作目录。将指定目录加入到 Claude 的工作空间中，
  可以同时处理多个目录下的文件。

/memory
  打开持久化记忆文件。Claude 会在 .claude/memory/ 目录
  存储关于你偏好、项目背景的长期记忆，跨会话保留。

四、AI 增强命令（AI Enhanced Commands）
================================================================================

/deep-research [研究主题]
  深度研究报告。对任意主题进行多源、交叉验证的深度研究。
  流程：并行搜索 → 获取来源 → 对抗性验证 → 生成引用报告。
  适合需要详实数据和多方论证的调研任务。

/claude-api
  Claude API / Anthropic SDK 参考。查询模型 ID、定价、
  参数、流式响应、工具使用、MCP、Token 计数等信息。
  当涉及 API 开发、模型选择、定价问题时使用。

/workflows
  查看和管理多代理工作流（Workflow）。工作流可以并行启动
  多个子代理，进行大规模代码审计、迁移、审查等任务。
  使用关键字 "ultracode" 可以触发多代理编排模式。

/tasks
  查看和管理任务列表。显示当前会话中的待办、进行中、
  已完成任务，支持建立任务依赖关系。

/agents
  查看可用代理类型。Claude Code 中不同类型的子代理：
  通用代理、探索代理、计划代理、代码审查代理等。

五、内容创作命令（Content Creation Commands）
================================================================================

/business-plan-generator
  商业计划书生成器。根据提供的商业项目信息，
  自动生成符合行业标准的专业商业计划书 Word 文档。
  触发词：商业计划书、生成商业计划、business plan。

/cheat-init
  内容创作平台的首次初始化与脚手架创建。
  触发词：初始化、init、首次使用、setup。

/cheat-bump
  升级评分公式（rubric）或重校分类桶（bucket）。
  两种模式：完整升级（高风险，5步+跨模型审核）
  和轻量重校（仅调整边界）。

/cheat-learn-from
  对标账号导入。从对标账号中学习内容策略。

/cheat-migrate
  Schema 版本迁移工具。

/cheat-persona
  受众画像派生。分析受众特征生成内容画像。

/cheat-predict
  AI 主导的盲预测 + 用户审核。

/cheat-publish
  发布登记。记录内容发布信息。

/cheat-recommend
  候选池排序推荐。对内容创意进行优先级排序。

/cheat-retro
  内容复盘。分析已发布内容的表现。

/cheat-score
  内容评分。根据评分标准对内容打分。

/cheat-score-blind
  盲评分。不参考历史数据独立打分校准。

/cheat-seed
  选题生成。基于受众画像生成内容选题。

/cheat-shoot
  拍摄辅助。内容制作过程的辅助工具。

/cheat-status
  查看内容平台当前状态。

/cheat-trends
  趋势分析。分析当前热门话题和趋势。

/qiuzhi-skill-creator
  技能创建向导。通过交互式 SOP 流程，
  一步步指导你创建自定义技能（Skill）。

六、MCP 与扩展命令（MCP & Extension）
================================================================================

/mcp
  管理 MCP（Model Context Protocol）服务器。
  MCP 允许 Claude 连接外部工具和数据源，
  如数据库、API、文件系统等。
  支持添加、移除、配置 MCP 服务器。

/hooks
  管理钩子（Hooks）。钩子是在特定事件触发时自动执行的脚本，
  如：保存文件后、提交前、Claude 启动/停止时等。
  配置文件在 settings.json 的 hooks 部分。

七、其他命令（Other Commands）
================================================================================

! [命令]
  直接在终端运行命令。在对话中输入 "! ls" 等同于在终端执行 ls。
  用于需要直接操作 shell 的场景。

Esc 键
  退出当前模式（如计划模式 Plan Mode）。

Ctrl+C
  中断当前正在执行的操作或 AI 回复。
